# CodeAlpha Random Quote Generator

A Flutter-based random quote generator application developed as part of the CodeAlpha App Development Internship.

## Overview

CodeAlpha Random Quote Generator is a simple and clean mobile application that displays inspirational and motivational quotes.

Users can generate a new random quote, copy quotes, and save their favourite quotes for later.

## Features

- Random quote generation
- New Quote button
- Different quote on each request
- Quote text and author display
- Favourite quotes
- Save and manage favourite quotes
- Copy quote to clipboard
- Clean and minimal user interface
- Smooth UI interactions
- Responsive Flutter UI
- Local quote collection

## Favourite Quotes

Users can mark quotes as favourites and access the quotes they like most through the favourite functionality.

## Copy Quote

Users can copy the currently displayed quote to their clipboard. A confirmation message is shown after successfully copying a quote.

## Technologies Used

- Flutter
- Dart
- Material Design
